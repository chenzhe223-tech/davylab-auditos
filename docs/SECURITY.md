# 安全与数据治理

## 默认行为
- 后端只监听本机回环地址。
- 不默认连接云端 AI，不自动上传工程文件。
- 本地项目数据不进入 Git。
- 日志记录任务 ID、状态和错误类别，不记录合同正文、身份证号、银行账户、密钥或完整报价。

## 用户责任
用户须确认拥有导入和处理合同、图纸、报价、人员信息等资料的合法授权，并遵守保密与个人信息保护义务。

## 云端模型
启用前展示服务商、模型、发送字段/文件范围、用途及第三方处理情况。默认仅发送用户选定的最小必要内容；上传原始附件必须单独明确操作。

## 禁止提交
真实合同、结算书、报价单、施工图、个人信息、客户/供应商资料、内部通信、密钥、Token、数据库、日志及未获授权传播的规范/定额/商业数据库内容。
