# 开发路线图

## Phase 0 — 基础治理
- [x] 产品章程、架构和审核方法边界
- [x] Apache-2.0 开源基线
- [ ] 贡献规范和安全策略持续完善

## Phase 1 — 可运行审核核心
- [ ] FastAPI 本地服务与健康检查
- [ ] 项目 CRUD、SQLite 持久化
- [ ] 结算 Excel 导入、预览、字段映射
- [ ] 行级数据质量检查
- [ ] Decimal 计算与合价差异校验
- [ ] 重复申报线索（不自动认定重复）
- [ ] 审核台账及人工状态流转
- [ ] XLSX 审核明细导出
- [ ] 测试样例、Windows 启动说明

## Phase 2 — 资料与合同
- [ ] 文件登记、SHA-256、版本和证据定位
- [ ] PDF/DOCX/XLSX 解析适配
- [ ] 合同计价条款候选提取与确认
- [ ] 缺失资料清单、文档关系
- [ ] 项目规则集版本化

## Phase 3 — 安装专业审核
- [ ] 电气、给排水、暖通、消防等专业工作流
- [ ] 清单特征与计量单位规则配置
- [ ] 用户合法提供的定额/价格来源适配
- [ ] 变更签证、认价和调差关联
- [ ] 费用税金审核配置
- [ ] DOCX 审核报告及一致性检查

## Phase 4 — AI Agent
- [ ] 模型供应商 adapter，默认关闭
- [ ] 文档和合同提取 Agent
- [ ] Audit Master 编排与工具白名单
- [ ] 可定位引用的受控 RAG
- [ ] 提示注入防护、不可信文件隔离
- [ ] 人工审批门及模型输出校验

## Phase 5 — 可交付产品
- [ ] React 工作台
- [ ] Windows 桌面打包评估
- [ ] 本地备份、恢复和项目归档
- [ ] 性能、安全和大文件测试
- [ ] 经用户授权的脱敏真实项目验收

## 阶段验收
每阶段提交功能说明、测试记录、已知限制和变更记录。计算功能必须具有单元测试、边界测试和可复算样例；规则结论必须注明来源与适用条件。
